# Smart Campus Energy & EV Fleet Management Dashboard

An interactive data analytics dashboard developed using **Python and Streamlit** to monitor and analyse campus electric vehicle (EV) charging activities, energy consumption, revenue, and operational performance.

## 1. Project Overview

The Smart Campus Energy & EV Fleet Management Dashboard is designed to provide a centralised view of electric vehicle charging operations within a campus environment.

The application processes charging-session data and presents meaningful information through interactive charts, performance indicators, statistical analysis, and operational alerts. It helps users understand energy consumption patterns, compare charging activities, monitor potential operational issues, and explore charging records.

## 2. Project Objectives

- Monitor overall campus EV energy consumption.
- Analyse hourly charging demand and usage patterns.
- Compare revenue generated by different charger types.
- Understand charging activities across different user categories.
- Examine relationships between battery temperature and energy consumption.
- Identify potentially high-risk sessions based on overstay duration and battery temperature.
- Provide interactive data filtering and CSV export functionality.

## 3. Key Dashboard Features

### Executive Overview
Provides an overall summary of charging operations through key performance indicators:

- Total Energy Delivered (kWh)
- Carbon Offset (kg CO₂)
- Total Revenue (MYR)
- Active High-Risk Alerts

It also includes hourly energy demand, revenue by user type, and charging sessions by charger type.

### Charging Analysis
Provides detailed insights into charging performance through:

- Revenue comparison between AC and DC chargers.
- Battery Temperature vs Energy Delivered analysis.
- Correlation heatmap of important energy and operational variables.

### Alert Centre
Identifies charging sessions that exceed both configured alert conditions:

- Battery temperature above the selected threshold.
- Overstay duration above the selected limit.

The identified sessions are displayed in a table for further inspection, together with their associated overstay fees.

### Filtered Data
Allows users to interact with the dataset using dashboard filters, inspect selected charging records, and download filtered results in CSV format.

## 4. Interactive Dashboard Controls

The dashboard includes the following filters:

| Filter | Description |
|---|---|
| Minimum Energy | Selects sessions based on minimum energy delivered |
| Charger Type | Filters AC and DC charging sessions |
| User Type | Filters Student, Staff, and Visitor records |
| Battery Temperature | Adjusts the battery temperature alert threshold |
| Overstay Duration | Adjusts the overstay alert threshold |

All relevant dashboard results update according to the selected filters.

## 5. Dataset Description

The project uses campus EV charging-session data containing **1,200 records**.

The dataset includes information such as:

- Session ID
- Charger Type
- User Type
- Starting Hour
- Charging Duration
- Energy Delivered
- Overstay Duration
- Battery Temperature
- Charging Power
- Carbon Savings
- Net Billable Amount

The processed dataset is used for the dashboard's analytical calculations and visualisations.

## 6. Data Processing and Analysis

Python libraries are used to clean, process, calculate, and analyse the charging-session data.

Some of the calculated variables include:

- **Charging Duration:** Converts charging time from minutes into hours.
- **Power Rate:** Calculates average charging power in kW.
- **Carbon Savings:** Estimates carbon savings based on energy delivered.
- **Base Charging Fee:** Calculates the base charging amount using the project's configured rate.
- **Net Billable Amount:** Applies an additional 15% when the overstay duration exceeds 20 minutes.

The project also uses statistical correlation analysis to examine relationships between selected numerical variables.

*Note: Carbon savings and billing amounts are estimates based on the calculation rules configured in the project.*

## 9. Running the Application

Install the required dependencies:

```bash
pip install -r requirements.txt
```

Start the Streamlit dashboard:

```bash
streamlit run app.py
```

The application will open in your web browser at:

```text
http://localhost:8501
```
